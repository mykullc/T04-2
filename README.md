# Appliance Energy Consumption Website

## About the Project

This is a university project for COS30045. The website provides information about appliance energy consumption in the Australian market, with a focus on televisions.

## Website Features

- Home page
- Televisions page
- About Us page
- JavaScript navigation between pages
- Power logo that returns to the Home page
- Current-page navigation feedback
- Mouse-over feedback for navigation links and buttons

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Copilot

## GenAI / AI Declaration

GitHub Copilot was used during development to:

- Generate the initial HTML structure
- Generate the basic CSS
- Generate the three-page HTML content
- Generate the JavaScript navigation
- Suggest the active navigation link
- Explain parts of the code

I reviewed, tested and modified the generated code myself.
